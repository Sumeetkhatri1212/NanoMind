Engineering Deep-Dive

How I Built Nano-Mind from Scratch

No PyTorch runtime. No ONNX. No black-box frameworks. Here is how the custom C++17 engine was engineered from the mathematical foundations to production.

01

C++17 Transformer Math

Implemented the complete GPT-2 transformer architecture in pure C++17: multi-head self-attention, layer normalization, exact GELU activation via tanh approximation, and stochastic top-k sampling.

Zero Deep Learning Frameworks
02

AVX2 & FMA SIMD Acceleration

Hand-optimized core matrix-vector multiplications using 256-bit x86 vector registers with Fused Multiply-Add (_mm256_fmadd_ps), calculating 8 single-precision float operations per clock cycle.

x86 Hardware Intrinsics
03

Autoregressive KV-Cache

Designed pre-allocated Key-Value caches across all layers to store past token representations. This eliminates O(n²) attention recalculations, turning autoregressive token decoding into constant O(1) steps.

O(1) Step Decoding
04

Zero-Copy Binary Model Loader

Engineered a proprietary binary model layout (model.bin) loaded directly via pointer arithmetic. Weights are mapped directly into contiguous RAM buffers, eliminating expensive memory duplication.

Zero memcpy Duplication
05

OpenMP Multi-Core Parallelism

Distributed multi-head attention loops and feedforward projection passes across multiple CPU cores using OpenMP pragmas, achieving near-linear scaling on modern multi-threaded CPUs.

Parallel Multi-Head Attention
06

Live SSE Streaming Backend

Created a lightweight server layer that bridges OpenAI's 50,257-token BPE vocabulary via tiktoken and pushes generated tokens live to the browser over Server-Sent Events with under 40ms TTFT.

Server-Sent Events (SSE)
